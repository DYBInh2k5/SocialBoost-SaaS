## [0.1.0] - 2026-03-24

### Added
- Initial Laravel 13 project bootstrap with Breeze authentication.
- Multi-tenant workspace model and membership relationships.
- Content template management scoped by active workspace.
- Scheduled post management with draft, scheduled, published, failed statuses.
- AI caption generation flow with OpenAI support and local fallback mode.
- Dashboard with basic social content KPIs.
- Queue job and scheduler command for dispatching due scheduled posts.
- Documentation set: README, architecture notes, release checklist, contributing guide.
- GitHub Actions workflow for automated test execution on push and pull requests.
